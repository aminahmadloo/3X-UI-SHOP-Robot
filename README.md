# 3X-UI-SHOP-Robot

ربات فروش، مدیریت و تحویل خودکار اشتراک VPN در تلگرام، متصل به **3X-UI**.

این پروژه برای راه‌اندازی یک فروشگاه واقعی اشتراک VPN طراحی شده است؛ از ثبت کاربر و انتخاب پلن تا پرداخت، ساخت سرویس در 3X-UI، تحویل لینک اشتراک، تمدید، کیف پول و مدیریت کاربران از داخل ربات.

## قابلیت‌های اصلی

### فروش اشتراک VPN

- نمایش پلن‌های فروش بر اساس مدت و تعداد دستگاه
- ایجاد و تمدید اشتراک
- اتصال مستقیم به 3X-UI برای ساخت و مدیریت سرویس‌ها
- تحویل لینک Subscription به کاربر پس از خرید
- مدیریت سرویس‌های فعال کاربر
- پشتیبانی از چند سرور 3X-UI
- امکان مدیریت وضعیت سرورها از داخل پنل مدیریت

### کیف پول

- افزایش موجودی کیف پول کاربر
- استفاده از موجودی برای خرید یا تمدید
- پرداخت هوشمند کارت‌به‌کارت برای شارژ کیف پول
- ثبت و پیگیری تراکنش‌ها

### پرداخت

در نسخه فعلی، ساختار پرداخت پروژه برای درگاه‌ها و روش‌های مورد استفاده این پروژه آماده شده است:

- **زرین‌پال**
- **آبان‌گیت‌وی** برای پرداخت هوشمند کارت‌به‌کارت
- **بلوپال** برای پرداخت هوشمند کارت‌به‌کارت

درگاه‌هایی که در پروژه استفاده نمی‌شوند، نیازی به تنظیم ندارند.

### سیستم دعوت

- لینک دعوت اختصاصی برای کاربران
- ثبت دعوت‌ها
- پاداش دعوت
- پشتیبانی از پاداش سطح اول و دوم
- امکان تنظیم پاداش به‌صورت مبلغی

### دوره آزمایشی

- کنترل فعال یا غیرفعال بودن Trial
- امکان تعریف Trial متفاوت برای کاربران دعوت‌شده

## نصب روی VPS جدید

### نصب خودکار Production

برای نصب تمیز روی VPS جدید، پروژه یک Installer در فایل `install.sh` دارد.

پیش‌نیاز پیشنهادی:

- Ubuntu 22.04، 24.04 یا 26.04
- معماری amd64 یا arm64
- دامنه‌ای که به IP سرور جدید اشاره کند
- دسترسی اینترنت به GitHub؛ در حالت Public نیازی به GitHub Token نیست.

نصب‌کننده به‌صورت خودکار موارد اصلی زیر را انجام می‌دهد:

1. بررسی سیستم‌عامل، معماری، پورت‌ها و DNS
2. دریافت کد پروژه
3. نصب Docker و Docker Compose
4. نصب و تنظیم Nginx
5. دریافت SSL از Let's Encrypt
6. ساخت فایل امن `.env`
7. ساخت `plans.json` در صورت نبودن
8. Build و اجرای کانتینرهای ربات و Redis
9. اجرای Migration دیتابیس
10. بررسی سلامت ربات و HTTPS

### اجرای Installer

Repository پروژه Public است و برای نصب نیازی به GitHub Token یا GitHub CLI ندارید:

```bash
curl -fsSL \
  -H "Accept: application/vnd.github.raw+json" \
  "https://api.github.com/repos/aminahmadloo/3X-UI-SHOP-Robot/contents/install.sh?ref=main" \
  | bash
```

> اگر Repository در آینده Private شد، Installer همچنان امکان استفاده از `GH_TOKEN` را دارد؛ در آن حالت باید Token با دسترسی `Contents: Read` قبل از اجرای Installer تنظیم شود.



> **مهم:** این Installer برای نصب تمیز است. SQLite، Redis، کاربران، سرویس‌های قبلی و وضعیت 3X-UI را از سرور قبلی منتقل نمی‌کند. مهاجرت سرور موجود باید با Backup/Restore جداگانه انجام شود.

## تعریف پلن‌ها

پلن‌های فروش در فایل `plans.json` قرار دارند.

نمونه ساختار پروژه:

```json
{
  "durations": [30, 60, 180, 365],
  "plans": [
    {
      "devices": 1,
      "prices": {
        "IRT": {
          "30": 100000,
          "60": 180000,
          "180": 450000,
          "365": 800000
        }
      }
    }
  ]
}
```

- `durations` مدت‌های قابل فروش را مشخص می‌کند.
- `devices` تعداد دستگاه مجاز را مشخص می‌کند.
- قیمت هر مدت در بخش `prices` قرار می‌گیرد.
- واحد پول فعلی نمونه پروژه `IRT` است.

> قیمت‌های موجود در نمونه فقط نمونه هستند و قبل از فروش واقعی باید با تعرفه فروش شما جایگزین شوند.

## تنظیم 3X-UI

برای استفاده از ربات باید یک یا چند پنل **3X-UI** در دسترس باشند.

در پنل 3X-UI:

1. دسترسی پنل را با HTTPS امن کنید.
2. حداقل یک Inbound مناسب برای ساخت سرویس کاربران داشته باشید.
3. سرویس Subscription را فعال و قابل دسترسی کنید.
4. پورت و مسیر Subscription را مطابق تنظیمات ربات قرار دهید.
5. اطلاعات دسترسی پنل را در `.env` وارد کنید.

ربات از 3X-UI به‌عنوان لایه مدیریت سرویس استفاده می‌کند؛ بنابراین ایجاد یا تمدید اشتراک باید با ساختار Inbound و Subscription واقعی سرورهای شما هماهنگ باشد.

## پشتیبان‌گیری

پروژه امکان پشتیبان‌گیری خارجی از اطلاعات مهم را دارد و برای ذخیره‌سازی S3-compatible، از جمله **Backblaze B2**، قابل تنظیم است.

متغیرهای اصلی:

```
FULL_BACKUP_STORAGE_ENABLED
FULL_BACKUP_STORAGE_ENDPOINT
FULL_BACKUP_STORAGE_BUCKET
FULL_BACKUP_STORAGE_ACCESS_KEY_ID
FULL_BACKUP_STORAGE_SECRET_ACCESS_KEY
FULL_BACKUP_STORAGE_REGION
FULL_BACKUP_STORAGE_URL_EXPIRES_SECONDS
FULL_BACKUP_STORAGE_PREFIX
```

برای محیط Production توصیه می‌شود Backup را روی فضای ذخیره‌سازی جدا از VPS نگهداری کنید.

## دستورات نگهداری

مشاهده وضعیت سرویس‌ها:

```bash
docker compose ps
```

مشاهده لاگ ربات:

```bash
docker compose logs --tail=100 bot
```

مشاهده زنده لاگ:

```bash
docker compose logs -f bot
```

Build مجدد:

```bash
docker compose build
docker compose up -d
```

## نکات مهم Production

- فایل `.env` شامل کلیدها و اطلاعات محرمانه است؛ آن را Commit نکنید.
- قبل از تغییرات مهم از دیتابیس و فایل‌های تنظیماتی Backup بگیرید.
- قبل از تغییر در درگاه پرداخت، Webhook و Callback آن را بررسی کنید.
- قبل از تغییر 3X-UI، وضعیت Inbound و Subscription را بررسی کنید.
- برای مهاجرت سرور، ابتدا Backup و سپس Restore انجام دهید؛ نصب‌کننده به‌تنهایی مهاجرت انجام نمی‌دهد.

## وضعیت پروژه

**3X-UI-SHOP-Robot** یک پروژه در حال توسعه است و قابلیت‌های آن بر اساس نیاز عملیاتی فروشگاه VPN توسعه داده می‌شوند.

تمرکز پروژه روی این چرخه است:

**کاربر ← ربات تلگرام ← پرداخت ← ایجاد/تمدید سرویس در 3X-UI ← تحویل Subscription**
